## 2026-10-04 計算基準・データ反映の最終修正
- 源泉徴収票がある年度でも、源泉徴収票をすべての項目で自動的に「正」としない構造へ変更。
- 支払金額、社会保険料、生命保険料控除、地震・旧長期損害、iDeCo、本人の国民年金、娘の国民年金、扶養・特定親族等、所得金額調整控除について、各項目ごとに「源泉徴収票」「給与・賞与ベース」のチェックボックスを表示。
- 両方の金額を画面上で比較でき、実際の計算には選択した側だけを使用。
- 源泉徴収票がない年度は「給与・賞与ベース」を自動選択。
- 手動入力は、源泉徴収票へ単純に加算するのではなく、「給与・賞与ベース」を構成するための値として反映。
- 確定申告などで源泉徴収票の内容と最終申告内容が変わる場合、該当項目だけ給与・賞与ベースへ切り替えて手動入力を反映できる。
- 旧 `useManual` 設定が残っているバックアップも読み込み時に新しい項目別基準へ移行する。


## 2026-10-03 手動入力・比較計算の再修正
- 「所得金額調整控除」は手動入力の反映先テーブルから削除。年収、年分制度、23歳未満扶養親族・特別障害者の状況から源泉徴収票ベース／給与・賞与ベースの両方で自動計算。
- 比較表に所得金額調整控除を表示し、両方の計算へ実際に反映された金額を確認できるよう修正。
- 娘の国民年金は、反映先をONにした側の社会保険料へ実際に加算し、比較表にも源泉側／給与側を別表示。
- 扶養・特定親族等は、反映先をONにした側の控除額へ実際に反映し、比較表も計算後の値を表示。
- 生命保険料控除は、源泉徴収票から取得できる自動値を通常使用するが、手動入力の源泉側チェックがONなら源泉票の生命保険料控除を使わず、手動入力から計算した控除額で上書き。
- 比較表は「表示上の元データ」ではなく、実際の計算に使った源泉徴収票ベース／給与・賞与ベースの値を表示する構造に修正。
- 源泉徴収票の日本語項目名を含む複数のフィールド名から、支払金額・社会保険料・生命保険料控除・地震保険料控除・iDeCo・扶養控除を取得できるよう補強。

## 2026-10-04 構造化JSON反映
- 最新の39資料（2024:給与12・賞与2・源泉1、2025:給与12・賞与2・源泉1、2026:給与8・賞与1）を前提に、同一資料は重複除外して反映できる構造を維持。
- 源泉徴収票の扶養人数は証拠文字列を再解析せず、`dependentGeneralCount` / `dependentSpecificCount` / `specialDependentCount` を構造化JSONから直接使用。
- 2025年の源泉徴収票は原票テキストをJSONへ保持し、一般扶養1人=380,000円、特定親族特別控除1人=630,000円を独立計算。
- 所得金額調整控除は手動の控除額入力ではなく、年収・年分制度・適用要件から自動判定。源泉徴収票記載の調整控除後金額から二重控除しない。
- 源泉徴収票ベースと給与・賞与実績＋予測ベースは独立計算し、手動入力の各項目は反映先を源泉側／給与賞与側で個別指定。
- 個人の実データJSONは公開アプリZIPには同梱しない。JSONはアプリの「JSONを反映」から端末内DBへ取り込む。Gitへ個人データを追加する前提にはしない。
