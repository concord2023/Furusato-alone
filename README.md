# ふるさと納税 上限管理（Standalone）

## 基本方針
このアプリは給与明細・賞与明細などのPDFをブラウザで読みません。
PDFはChatGPTのLibraryにアップロードし、ChatGPTが資料を確認・整理してアプリ用データを更新します。
アプリは同梱の `furusato-data.json` を起動時に自動同期し、端末内IndexedDBへ保存して計算します。

## ユーザーの使い方
1. ChatGPTのLibraryへ給与明細・賞与明細・源泉徴収票をアップロードする。
2. ChatGPTへ「ふるさと納税アプリへ反映して」と依頼する。
3. ChatGPTは重複を除き、既存データとの差分を確認し、`furusato-data.json` の更新データを作る。
4. その更新データをGitHub Pagesのアプリへ反映する。
5. アプリを再読み込みすると自動同期される。

※現状のGitHub PagesはChatGPTのLibraryを直接参照できません。そのため、ChatGPTとアプリの間はアプリ用データファイルで橋渡しします。PDFをアプリへアップロードする操作は不要です。

## アプリ内の手動入力
年度ごとに次を保存できます。
- 特別支給額
- 生命保険料控除
- 地震保険料控除
- iDeCo・小規模企業共済等
- 給与課税対象額への調整
- メモ

入力値は端末内DBへ保存し、変更直後に予測・上限試算へ反映します。

## 計算ステージ
- 給与は課税対象額を基準に使用。
- 12月実績がなければ、保存済み1〜11月実績から12月を予測。
- 12月実績が入ったら予測値を実績へ置換。
- 源泉徴収票は予測段階では使わず、実績反映後の比較・最終計算用データとして保持。
- 賞与は保存済み実績を使用し、根拠のない推測値は自動追加しない。

## データ更新
`furusato-data.json` はアプリの自動同期用データです。ファイル名は固定してください。
アプリには「取り込み」ボタンを置かず、起動・再読み込み時にこのファイルを自動同期します。
更新後はアプリを再読み込みします。
