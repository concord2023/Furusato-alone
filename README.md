# ふるさと納税 上限管理（standalone）

- GitHub Pages側に個人の給与・賞与・源泉徴収データを置かない
- ChatGPT Libraryで資料を読み取り、構造化JSONをアプリへ貼り付けてIndexedDBへ保存
- `type`/ネストされた2024資料も `kind` 等へ正規化して `unknown` を解消
- 読み取った全項目をDBに保存し、各資料からJSON全文を画面で確認可能
- 手動入力は年度別に保存し、保存完了メッセージと計算への反映を表示
- 生命保険料控除は新/旧生命、新/旧個人年金、介護医療を内訳表示し、合計を12万円上限で表示
- 娘の国民年金を社会保険料控除として入力可能。対象に含める/含めないを明示
- 源泉徴収票は予測計算に使わず、保存・比較用
