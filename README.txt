# ふるさと納税 上限管理（Standalone）

給与明細PDFそのものをブラウザで解析する方式は採用せず、チャット側で読み取った構造化データ（JSON）を取り込んで、端末内DBに保存・計算する構成です。

## 現在の予測ステージ
- 2025年1〜11月の実績から12月給与を予測
- 手動入力は0円
- 源泉徴収票はこのステージでは使用しない
- 12月給与は1〜11月の課税対象額平均で予測
- 社会保険料は1〜11月平均で12月を予測
- 賞与は実績データが取り込まれるまで推測で補完しない
- 予測値と根拠を画面に表示

## データ取り込み
「読み取り済みデータを取り込む」からJSONを選択します。形式は `{ "documents": [...] }` または配列です。
給与データには少なくとも `year`, `month`, `taxable`, `social` を入れ、その他の項目も保存できます。

## 次の段階
1. 2025年12月給与・賞与をチャット側で読み取り、JSONとして取り込む
2. 実績で予測を置き換える
3. 源泉徴収票をチャット側で読み取り、最終計算ステージへ切り替える
4. 予測値・実績値・源泉徴収票ベースの値を比較できるようにする
